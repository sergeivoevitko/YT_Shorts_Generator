# Bundled third-party assets

- `fonts/Anton-Regular.ttf`, `fonts/Bangers-Regular.ttf`, `fonts/BebasNeue-Regular.ttf`,
  `fonts/Poppins-ExtraBold.ttf`, `fonts/Poppins-SemiBold.ttf`: from Google Fonts, each under the
  SIL Open Font License 1.1 (text in `fonts/OFL-LICENSE.txt`; copyright belongs to each font's authors).
- `models/yunet.onnx`: YuNet face detector (`face_detection_yunet_2023mar.onnx`) from the OpenCV Zoo, MIT License.
- `emoji/*.png`: Noto Emoji images (release v2.047) by Google, Apache License 2.0. Other emojis are
  downloaded from the same release on first use and cached in `workspace/emoji/`.
